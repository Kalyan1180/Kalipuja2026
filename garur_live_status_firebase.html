Setup & notes

FIREBASE_DB_URL and FIREBASE_AUTH are already configured in this file.

This page only ever reads from Firebase. The auth value is included in the page URL when requests are made, so use a Firebase credential intended for client-side read access only.

The "you're on the show network" panel only appears if this page can actually reach the Hub's local address. If you host this page over HTTPS, browsers block that check from reaching a plain-HTTP local device (mixed content) — for that panel to work, open this file locally or host it over plain HTTP on your own network instead.

"Last seen" is read from the timestamp built into Firebase's own event keys, not the device's clock — so it stays accurate even if a device's clock is wrong.
