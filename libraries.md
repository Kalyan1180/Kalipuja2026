# Required Libraries

## ESP8266 sensor node

Install ESP8266 board package in Arduino IDE.

Built-in/core libraries used:

```text
ESP8266WiFi
ESP8266WebServer
EEPROM
espnow
user_interface
ESP8266HTTPUpdateServer
```

## ESP8266 hub brain

Install ESP8266 board package.

Libraries used:

```text
ESP8266WiFi
ESP8266WebServer
WiFiUdp
SoftwareSerial
EEPROM
espnow
user_interface
```

## Arduino Nano slave

Install:

```text
DFRobotDFPlayerMini
Servo
SoftwareSerial
```

DFPlayer SD card layout:

```text
/mp3/0001.mp3 = calm Garur bird / ambience
/mp3/0002.mp3 = fight sound
/mp3/0003.mp3 = victory / celebration sound
/mp3/0004.mp3 = idle low ambience
```
